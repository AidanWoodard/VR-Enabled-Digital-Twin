# Purpose

This repo is a collection of `ROS Noetic` nodes and library references for a digital twin of the `NXROBO Sagittarius` robot arm. This project was a 10-week **REU** (Research Experience for Undergraduates) program at **Kent State University** within Kent State's XR Lab.
